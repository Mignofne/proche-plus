## Traits LOCKED (identité)

- Ours brun dodu, corps entier, texture peluchée illustrée
- Espiègle / joyeux, regard malicieux
- Mèche blanche (~60 ans)
- Mono-sourcil brun (Frida-like)
- **Pattes d’oie** discrètes
- **Gilet crème** + fleurs mexicaines (défaut)
- **Pas de nœud papillon**

## VARIABLE

- **Motif du gilet** — swappable / fun ; face + corps fixes

## Scènes générées — règles LOCKED (fondateur)

1. **Aucun humain** — jamais de personne ni silhouette humaine. Compagnon / aidant / interlocuteur = **un autre ours Proche+** uniquement (même identité face/corps C-v3).
2. **Deux ours ou plus — gilets distincts (fondateur)** :
   - **Ours primaire** (patient / héros) : identité C-v3 complète, **gilet crème fleurs mexicaines**.
   - **Ours compagnon** (aidant / second) : **même face/corps** (brun dodu, mèche blanche ~60, mono-sourcil, pas de nœud) mais **gilet neutre** — crème/beige uni ou soft solid, **sans motif floral mexicain**, pour les distinguer visuellement.
3. **Jamais par terre** — dignité & sécurité rééducation. Les ours sont **assis sur un siège** (chaise, fauteuil, canapé, bord de lit, fauteuil roulant, etc.). Jeux / cartes / supports d’exercice **sur une table**, jamais au sol.
4. **Jamais vulgaire, sexuel, érotique, suggestif ou à double sens.**
5. Ton rééducation / éducation : **respectueux, chaleureux, espérant** — pas de violence, gore, humiliation, ni sensationnalisme de traumatisme médical.
6. Rating **family-safe** (aucun contexte sexualisé ; garde-fou mineurs explicite même si personnages = ours).

Violations → rejet client + serveur (pas de génération).
