# Générations Studio Ours (stills → vidéo)

Dossier de dépôt pour les stills produits par le skill **`bmad-studio-ours`** (ou l’atelier fondateur), destinés au rendu Remotion.

- Chemins utilisés dans les props : `/community-assets/ours-canon/generations/<fichier>.png`
- Composition vidéo multi-plans : `ProchePlusStoryboard` / `ProchePlusStoryboardFacebook`
- Rendu : `npm run community:render-video -- --composition=ProchePlusStoryboard --props=<json>`

Les PNG / MP4 générés ici peuvent rester locaux (non commités) sauf validation fondateur.
