## Template script vidéo YouTube (10-15 min)

```
Titre : [Question complète]
Persona ciblé : [Danièle / Michel / Corinne / Patrick / Françoise]

Accroche (0-30s) : pourquoi regarder cette vidéo, quel problème ça résout
Corps (structuré en 3-4 points clairs, avec rappel régulier du fil conducteur)
Conclusion : récap + où trouver plus d'info (lien description, jamais dans la vidéo elle-même de façon insistante)
```
