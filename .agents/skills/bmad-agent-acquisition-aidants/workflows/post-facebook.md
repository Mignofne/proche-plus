# Workflow — FB Post Facebook

## Goal

Produire un post page Proche+ (ou une réponse pour groupe tiers) utile, non promotionnel, persona-aware — aligné sur les 3 finalités communauté (discovery, preuve buyer, distribution organique).

## Load

- `references/objectif-communaute.md`
- `references/personas.md`
- `references/canaux-community.md`
- `references/templates.md`
- `references/humour-et-ton.md`
- `references/garde-fou-legal.md`
- `references/vision-proche-plus.md`

## Steps

1. **Collecter** :
   - surface : page Proche+ **ou** groupe tiers
   - rubrique (conseil / témoignage / glossaire / léger) — pour page
   - persona + moment de visite
   - sujet
   - contexte dosage humour du mois (max 1 léger / 4)
   - insight recherché (quelle matière qualitative on veut faire remonter)

2. **Règles surface** :
   - Groupe tiers → zéro promo en ouverture ; ressources utiles d'abord ; lien Proche+ seulement si pertinent et en fin
   - Page → CTA doux (question ouverte ou lien article), jamais lien app
   - Format transmissible pair-à-pair sans expliquer Proche+ (finalité 3)

3. **Rédiger** selon template post Facebook :
   - Accroche 1–2 lignes qui fonctionne sans « voir plus »
   - Corps 3–5 lignes
   - CTA = **vraie question de recherche** (irritant / formulation / moment de bascule), pas un prétexte à engagement
   - Quand pertinent : identité commune (« nous, les aidants… ») plutôt qu'adresse à une masse

4. **Filtre humour + légal** (y compris anticipation des réponses community : émotion OK, fond médical non).

5. **Présenter** + noter l'insight attendu + proposer une variante de ton si utile (sauf Corinne / urgence).

6. **Écrire** sous `{implementation_artifacts}/acquisition/fb-{rubrique}-{sujet}.md` après accord.

7. **Après publication** (rappel) : consigner les verbatims utiles ; ne jamais recopier une pathologie identifiable sans accord documenté.
