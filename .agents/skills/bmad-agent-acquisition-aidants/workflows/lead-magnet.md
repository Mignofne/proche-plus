# Workflow — LM Lead magnet

## Goal

Produire un lead magnet PDF (prioritaire : guide des 5 démarches post-hospitalisation) — chaleureux, sérieux, zéro humour, logo discret.

## Load

- `references/templates.md`
- `references/piliers-seo.md` (pilier démarches)
- `references/sequences-nurturing.md` (alignement déclencheur email)
- `references/garde-fou-legal.md`
- `references/vision-proche-plus.md`
- `references/personas.md`

## Steps

1. **Collecter** :
   - sujet (défaut = guide 5 démarches / 30 jours post-hospitalisation parent âgé)
   - persona principal (souvent multi-persona : Michel + Patrick + Françoise pour démarches)
   - longueur cible / nombre de démarches

2. **Contraintes** :
   - Zéro humour
   - Aucun conseil médical
   - Marque discrète (logo fin / couverture légère)
   - Contenu utile même sans Proche+
   - Pas de lien app ; éventuelle mention marque en fin seulement

3. **Structurer** :
   - Couverture + promesse claire
   - Intro courte (pourquoi ces 30 jours comptent)
   - 5 démarches numérotées, langage humain, checklist actionnable
   - « Quand parler à un pro » (orientation, pas conseil médical)
   - Fin discrète Proche+ (1–2 lignes) si phase post-lancement

4. **Filtre légal** exhaustif.

5. **Présenter** plan + texte prêt mise en page.

6. **Écrire** sous `{implementation_artifacts}/acquisition/lm-{sujet}.md` après accord.
