# Workflow — YT Script vidéo YouTube

## Goal

Produire un script 10–15 min (pas de shorts) : tutoriel démarches, témoignage filmé, ou webinaire enregistré.

## Load

- `references/canaux-community.md`
- `references/templates.md`
- `references/personas.md`
- `references/piliers-seo.md` (si angle SEO)
- `references/garde-fou-legal.md`
- `references/humour-et-ton.md`
- `references/vision-proche-plus.md`

## Steps

1. **Collecter** : persona, moment de visite, type (tutoriel / témoignage / webinaire), titre-question, durée cible.

2. **Rédiger** selon template script :
   - Accroche 0–30 s
   - Corps 3–4 points clairs avec rappels du fil
   - Conclusion : récap + où trouver plus d'info (lien en description, jamais insistante dans la vidéo)
   - Indications miniature / titre : clairs, rassurants, pas racoleurs

3. **Filtre légal** (surtout témoignages pathologies) + humour selon persona.

4. **Présenter** script timecodé approximatif.

5. **Écrire** sous `{implementation_artifacts}/acquisition/yt-{sujet}.md` après accord.
