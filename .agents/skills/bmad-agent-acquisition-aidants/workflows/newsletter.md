# Workflow — NL Newsletter / email

## Goal

Produire un email (newsletter récurrente ou pièce de séquence) : un seul sujet, objet non putaclic, signature humaine. Si question ouverte : vraie question de recherche (discovery), pas engagement bait.

## Load

- `references/objectif-communaute.md`
- `references/sequences-nurturing.md` (si pièce de séquence)
- `references/templates.md`
- `references/personas.md`
- `references/vision-proche-plus.md`
- `references/garde-fou-legal.md`
- `references/canaux-community.md`

## Steps

1. **Collecter** :
   - type : newsletter récurrente **ou** email N de la séquence Bienvenue (1–5)
   - persona principal
   - sujet unique
   - si séquence : respecter le timing et le niveau de mention Proche+ (mot « Proche+ » seulement à partir de l'email 4)
   - si question ouverte : insight recherché

2. **Rédiger** selon template email :
   - Objet factuel
   - Intro 2 lignes chaleureuses
   - Un seul sujet principal
   - Un seul lien principal
   - Question ouverte = recherche (optionnel mais prioritaire sur E3 de la séquence Bienvenue)
   - Signature prénom réel (demander le prénom si inconnu ; placeholder `[Prénom]` OK)

3. **Filtre légal** + surface bêta (pas de lien app).

4. **Présenter** objet + corps + notes (lien unique, insight attendu, flags).

5. **Écrire** sous `{implementation_artifacts}/acquisition/nl-{sujet}.md` après accord.
