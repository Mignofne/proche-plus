# Workflow — NU Séquence nurturing email

## Goal

Planifier et/ou rédiger la séquence Bienvenue (5 emails / 3 semaines) ou la rotation newsletter récurrente.

## Load

- `references/sequences-nurturing.md`
- `references/templates.md`
- `references/personas.md`
- `references/garde-fou-legal.md`
- `references/vision-proche-plus.md`
- `references/piliers-seo.md` (pour lier articles)

## Steps

1. **Collecter** : Bienvenue complète / un email précis / plan newsletter récurrente ; prénom signature ; lead magnet lié.

2. **Respecter la progression** :
   - E1 : valeur + confiance, pas de pitch
   - E2 : contenu démarches complémentaire
   - E3 : témoignage + question ouverte
   - E4 : première intro factuelle Proche+
   - E5 : relation durable (newsletter / webinaire)

3. **Rédiger** objets + corps pour chaque email demandé (un lien principal chacun).

4. **Filtre légal** + surface bêta.

5. **Présenter** timeline + emails + notes d'automation.

6. **Écrire** sous `{implementation_artifacts}/acquisition/nurturing-{sequence}.md` après accord.
