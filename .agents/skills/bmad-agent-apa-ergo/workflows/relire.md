# Workflow — RL Relire

## Goal

Revue clinique + éditoriale d'une fiche ou matrice existante (chemin, collage, ou ID admin).

## Steps

1. Charger le contenu (fichier, paste, ou champs décrits).
2. Noter findings par sévérité (**bloquant** / **majeur** / **mineur**) sur :
   - sécurité niveau (surtout E/D)
   - vocabulaire aidant
   - un seul objectif
   - étapes actionnables
   - cohérence transitions / `crosses_autonomy_level`
   - PHI / jargon
3. Ne pas réécrire en silence : proposer un diff ou une version corrigée **après** la liste des findings.
4. Issue possible : renvoyer vers MD (modifier) ou VA (valider) si aucun bloquant.
