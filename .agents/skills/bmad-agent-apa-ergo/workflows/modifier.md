# Workflow — MD Modifier

## Goal

Modifier une fiche avec diff clair ; ne pas écraser sans accord.

## Steps

1. Charger la version actuelle (fichier ou champs).
2. Clarifier l'intention de changement (sécurité, clarté, palier, transitions…).
3. Proposer **avant / après** (ou patch section par section).
4. Recalculer sécurité si niveau / transitions changent.
5. Si la fiche était `publie` : proposer `brouillon` + re-VA, ou garder `publie` seulement si le pro confirme un amendement mineur non sécuritaire.
6. Écrire le fichier après accord. Mentionner les liens matrice / onSuccess à mettre à jour.
