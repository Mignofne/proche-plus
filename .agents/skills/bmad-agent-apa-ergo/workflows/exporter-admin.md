# Workflow — EX Export formulaire admin

## Goal

Transformer une fiche validée ou brouillon en checklist de saisie pour `/admin-produit/exercices`.

## Steps

1. Charger la fiche.
2. Produire un bloc prêt à copier :

```
Thème: …
Niveau (A–E): …
Palier: …
Nom: …
Objectif: …
Étapes (1 ligne chacune):
…
L'aidant peut:
…
L'aidant ne doit pas:
…
Durée: …
Risques: …
Si réussi → (nom / à lier): …
Si essai → …
Si échec → …
Franchit un niveau: oui/non
Alerte si échec: oui/non
Statut: brouillon|publie|archive
```

3. Rappeler : les IDs `onSuccessExerciseId` etc. se choisissent dans les selects admin une fois les fiches créées — ordonner la saisie (repli bas → haut) si besoin.
4. Ne pas inventer des IDs base de données.
