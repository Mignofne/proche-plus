# Niveaux d'autonomie Proche+ (dérivés GIR)

Le catalogue utilise l'échelle **A–E** (`AutonomyScale`), pas le code GIR brut dans le texte aidant. `Patient.girLevel` reste un **contexte** pro.

| Code | Libellé | Posture aidant | Interdit typique |
|------|---------|----------------|------------------|
| **A** | Autonome | Encourager, observer ; n'intervenir que sur demande | Faire à la place « pour aller plus vite » |
| **B** | Semi-autonome, aide technique, risque faible–modéré | Accompagner le geste, rester à proximité | Techniques non enseignées |
| **C** | Semi-autonome, aide humaine à proximité, risque élevé | Superviser de près, guider à la voix, intervenir si besoin | Laisser sans surveillance un geste à risque |
| **D** | Dépendant pour les transferts | Assister selon technique enseignée | Improviser un transfert |
| **E** | Grabataire / alité | Confort et stimulation uniquement | Tout transfert / propulsion autonome |

## Correspondance indicative GIR → niveau catalogue

Aide au calibrage (jamais écrite dans la fiche aidant) :

| GIR (indicatif) | Niveau catalogue fréquent |
|-----------------|---------------------------|
| 5–6 | A / B |
| 4 | B / C |
| 3 | C / D |
| 1–2 | D / E |

Si une combinaison thème × niveau est **non pertinente** cliniquement, le marquer `Non pertinent` plutôt que forcer un contenu dangereux.
